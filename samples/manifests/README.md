# Public sample manifests

These manifests identify public, redistributable regression inputs without committing the binary files to the repository. A sample must be downloaded to an ignored local workspace, have its SHA-256 verified, and be processed read-only.

`freemote-title-pimg.json` records a CC0 PIMG sample from FreeMote.Samples. It establishes PIMG container and embedded TLG5 metadata regression only; it makes no claim about TLG6 decoding or any commercial game.
