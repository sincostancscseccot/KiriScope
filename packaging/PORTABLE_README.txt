KiriScope portable package
==========================

Start the graphical application with KiriScope.Gui.exe.
Run command-line operations with KiriScope.Cli.exe.

This package is self-contained for Windows x64. It also includes separately
published x64 and x86 runtime-evidence workers in workers\; no system .NET
installation is required for normal use or the explicit runtime snapshot flow.

The application never modifies an input game directory by default. Create
reports, conversions, and exports in a separate work directory. Runtime
capture remains explicitly opt-in and records only process/module metadata.

See README.md and THIRD_PARTY_NOTICES.md for capabilities, evidence limits,
and third-party notices.
