# 标准 XP3 重打包

`xp3 pack` 从用户明确指定的暂存目录创建一个**全新**标准 XP3 文件。它面向已授权的测试、研究和可复现验证，不会修改原始归档、游戏目录或暂存目录中的任何文件。

```powershell
kiriscope xp3 pack <staging-directory> <new-archive.xp3>
```

首个阶段 7 实现只写入：未加密、未压缩、每个文件一个分段的标准 XP3 索引。条目名称由暂存目录的相对路径稳定排序，使用 `/` 分隔符；每条记录包含长度、Adler-32 和复制时计算的 SHA-256，输出 JSON 同时记录新归档的 SHA-256、索引偏移和来源文件。

## 安全与一致性边界

- 输出必须位于暂存目录之外，且目标路径必须尚不存在；写入经由临时文件和无覆盖移动完成。
- 只枚举普通文件，不跟随重解析点；默认最多 250,000 个条目、单文件 2 GiB、总计 16 GiB。
- 打包时发现源文件长度或写入时间变化会失败并清理临时输出。
- 打包后应以 `xp3 list` 和 `xp3 extract` 对新归档做读取/提取回归验证；创建归档不代表目标游戏一定接受松散文件或该归档。

当前不支持加密索引、加密条目、压缩数据段、嵌入 EXE、KiriKiri Z 专用布局、对既有归档的原位编辑，或任何自动部署到游戏目录的操作。作品专用过滤后的内容只有在其来源、参数和格式验证已单独记录时，才适合进入暂存目录。
