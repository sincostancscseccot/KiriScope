# 发布说明

## 0.1.0-preview.9

- GUI 新增“XP3 归档与方案”标签：可在用户选择的目录内只读发现 XP3，读取索引并显示条目、压缩和加密标记摘要。
- 可显式选择已有 scheme JSON，并在一个已标记加密条目上执行受限验证；只有输出达到 `FormatValidated`，方案才可用于该归档的全量导出。
- GUI 导出仅写入全新的、归档目录之外的目标目录；无方案时仍可导出未标记加密条目，其他条目会作为跳过项保留诊断。
- 更新快速上手和能力矩阵，明确 GUI 向导不是密钥搜索或自动游戏兼容性判定。

### 已验证

- GUI 项目编译通过，且全量 .NET 测试与格式检查通过。

### 已知边界

- GUI 一次仅验证用户选择的一个已有方案，不会扫描目录、加载外部 DLL 插件或自动猜测算法/密钥。

## 0.1.0-preview.8

- GUI 完成简体中文本地化：窗口、按钮、文件对话框、状态文本、运行时授权提示、报告字段、证据等级和诊断严重性均以中文显示。
- 底层诊断代码与原始消息仍会随中文严重性标签显示，保留问题检索、自动化与可复现研究所需的技术细节。
- 单文件 GUI 重新构建为汉化版；完整便携版和安装版在下次完整发布构建时将自动使用同一套中文 GUI。

### 已验证

- GUI 项目编译通过，且格式检查通过。
- 单文件 GUI 将进行新的启动烟雾测试和内嵌 worker 资源检查。

## 0.1.0-preview.7

- 新增 Windows x64 单文件 GUI 发布：`KiriScope.Gui-0.1.0-preview.7-win-x64.exe`。它自包含 .NET 运行时，普通 GUI 资源分析不需要任何旁文件。
- 为保持显式运行时采集功能，x86/x64 worker 已嵌入单文件 GUI。仅当用户填写 PID、勾选授权并启动采集时，才会临时展开对应 worker 并在启动前校验其 SHA-256。
- 新增 `Build-GuiSingleFile.ps1`；完整便携版与安装版的构建流程保持不变。

### 已验证

- 全量 .NET 测试通过。
- 单文件发布目录仅保留一个 GUI EXE，且可在隐藏启动烟雾测试中保持运行。
- GUI 程序集中包含两个内嵌 worker 资源。

### 已知边界

- 单文件 GUI 仅支持 Windows x64，不包含 CLI，且当前未签署 Authenticode；下载后应核对发布页 SHA-256。
- 运行时 worker 的临时展开仍严格受 GUI 的显式授权开关控制，不会在普通启动或资源检查时发生。

## 0.1.0-preview.6

- 提供自包含的 Windows x64 便携版 ZIP 与当前用户范围的 Inno Setup 安装包。
- 包含 GUI、CLI、x64 worker 与 x86 worker；运行时证据采集仍必须显式启用，且只读进程/模块元数据。
- 新增发布构建校验：版本目录拒绝覆盖、SHA-256 清单、可选 Authenticode 签名与时间戳。
- 安装向导提供英语、简体中文及日语；未本地化的罕见 Inno Setup 引擎消息会回退英文。

### 已验证

- 全量 .NET 测试通过。
- 便携版可以启动 CLI，并找到包内 x64 worker 执行对当前进程的只读运行时快照。
- 安装包可静默安装到新目录，安装后的 GUI、CLI、两个 worker 与卸载器均存在。

### 已知边界

- TLG6 当前验证容器和元数据；原生像素解码需以可再分发或已授权的真实样本建立回归后再声明支持。
- 各作品的 XP3 加密不能由文件名或启发式自动推断；只有完整结构验证过的、带来源记录的方案才可标为兼容。
- 发布构建只有在传入本机证书指纹时才会产生受信任的 Authenticode 签名；SHA-256 清单始终生成，ZIP 不适用 Authenticode。
